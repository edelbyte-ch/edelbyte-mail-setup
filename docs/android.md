# Android

Android bindet fremde Kalender/Kontakte nicht nativ wie Apple ein. Deshalb
zweiteilig, ohne falsche Versprechen:

## E-Mail

Gmail, Samsung E-Mail, Outlook für Android u. a.: Konto hinzufügen → „Sonstige",
Adresse + Passwort. Server bei Bedarf: `mail.edelbyte.ch`, IMAP 993 SSL, SMTP
465 SSL, Benutzername = ganze Adresse.

## Kalender & Kontakte

Über **DAVx⁵** (quelloffen, Play Store/F-Droid): „Mit E-Mail-Adresse anmelden",
Adresse + Passwort; Server wird automatisch gefunden. Kalender/Kontakte
ankreuzen.

## Ausblick

Langfristig ist eine eigene EdelMail-App möglich (Projekt „EdelMail" existiert
bereits als Webmail). Der aktuelle Auftrag deckt Windows und Apple als
Ein-Schritt-Flow ab; Android bleibt bei der ehrlichen Zwei-App-Lösung.
